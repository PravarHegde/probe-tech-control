# Probharath Auro O Standard

The **Standard** is the balanced workhorse of the Auro O series. It gives you the smart features of TMC drivers while still allowing you to attach a physical screen.

## Key Features
- **Drivers:** 5x Smart TMC Drivers (TMC2208 / TMC2209).
- **UART:** Shared Bus. All drivers communicate over a single pin (`PA9`) using hardware addressing.
- **Extruders:** Single Nozzle.
- **Display:** Full Support! Features an I2C OLED/LCD header (`PB10` & `PB11`) and headers for simple navigation buttons.

## Why choose the Standard?
By putting all the smart drivers onto a shared communication bus, we saved 4 pins on the microcontroller. This means you get stealthchop, stallguard, and software current control, but you *still* have the pins necessary to plug in a physical display!
