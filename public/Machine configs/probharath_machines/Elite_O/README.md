# Probharath Elite O

The **Elite O** is the premium motherboard offering from Probharath Technologies, powered by the robust 64-pin STM32G0B1 microcontroller.

Designed for high-performance CoreXY 3D printers, the Elite O breaks free from the IO constraints of the Auro series, offering expanded connectivity for advanced Klipper features like ADXL345 resonance compensation, CAN bus toolheads, and dedicated RGB control.
