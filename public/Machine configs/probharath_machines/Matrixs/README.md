# Probharath Matrixs

The **Matrixs** is the flagship multi-MCU architecture from Probharath Technologies.

Instead of relying on a single monolithic microcontroller, the Matrixs architecture is built around a CAN bus ecosystem. It allows for modular expansion, seamlessly linking the main chassis control board with intelligent, lightweight toolhead boards.
