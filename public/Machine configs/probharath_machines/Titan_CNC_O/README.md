# Probharath Titan CNC O

The **Titan CNC O** is a heavy-duty control board engineered specifically by Probharath Technologies for Subtractive Manufacturing (CNC Routers, Mills) and Laser Engravers.

Unlike our 3D printer boards, the Titan CNC O is ruggedized for high-voltage external stepper drivers and features optically isolated IO to protect the MCU from high-frequency electrical noise generated by spindles and plasma cutters.
